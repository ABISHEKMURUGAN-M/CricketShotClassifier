## 2025-05-14 - Scannability and Progressive Disclosure in Documentation
**Learning:** Large, dense data tables (like the 36-column CSV example in this README) can significantly hinder document scannability and overwhelm users. Using the `<details>` element provides progressive disclosure, keeping the data available for those who need it while maintaining a clean, scannable overview for most users.
**Action:** Use `<details>` tags for large code blocks or data samples in README files to improve the overall reading experience.

## 2025-05-14 - Contextual Clarity in Data Visualizations
**Learning:** Notebook plots without titles, axis labels, and legends are difficult to interpret quickly, especially for users not deeply familiar with the code generating them. Adding these elements significantly reduces cognitive load.
**Action:** Always include titles, labels, and legends in data visualization plots to ensure they are self-descriptive.
