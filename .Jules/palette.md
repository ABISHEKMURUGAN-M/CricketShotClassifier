## 2025-05-14 - Distinguishable Plot Markers for Accessibility
**Learning:** In notebook plots, using different colors is not enough for colorblind accessibility. Using unique markers (like 'o' and 'x') and line styles (like '-' and '--') allows users to distinguish between multiple data series regardless of color perception.
**Action:** Always use a combination of unique markers and line styles when plotting training vs validation metrics in Jupyter Notebooks.
