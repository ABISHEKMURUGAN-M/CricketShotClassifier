## 2025-05-18 - Distinguishable Plot Elements for Colorblind Accessibility
**Learning:** Default line plots without explicit markers or distinguishable line styles rely solely on color to differentiate datasets (such as training vs. validation accuracy), rendering them inaccessible to colorblind users.
**Action:** Always include distinct markers (e.g. 'o', 'x'), line styles (e.g. '-', '--'), explicit axis labels, titles, and legends placed to avoid overlapping data points.
