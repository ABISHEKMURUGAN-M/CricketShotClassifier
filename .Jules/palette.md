## 2025-05-14 - Colorblind Accessible Plots
**Learning:** Using only different colors in plots can be inaccessible to colorblind users. Combining different line styles and markers ensures data series remain distinguishable.
**Action:** Always use distinguishable markers (e.g., 'o', 'x') and line styles (e.g., '-', '--') in addition to color when plotting multiple data series in notebooks.
