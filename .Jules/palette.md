## 2024-08-06 - Accessible Model Accuracy Plots & Decoded Outputs in Notebooks
**Learning:** Visualizations like model training and validation accuracy curves must be accessible to colorblind users. Using default overlapping lines makes them indistinguishable; combining distinguishable markers ('o' vs 'x') with unique line-styles ('-' vs '--') resolves this. Additionally, keeping raw label-encoded integer predictions rather than decoding them with inverse_transform forces the user to manually cross-reference, creating friction and leading to poor micro-UX.
**Action:** Always include title, axes labels with units, distinguishable markers, line-styles, and legends in all notebook data plots. Ensure all prediction classification outputs are automatically decoded back to human-readable format before presenting.
