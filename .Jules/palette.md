## 2023-10-27 - Colorblind-Accessible Notebook Plot & Readable Model Output UX
**Learning:** Standardizing notebook accuracy plots with explicit title/axis labels, distinguishable marker/line combinations, and descriptive legend positions (e.g., "lower right") significantly enhances usability for colorblind and screen-reader users. In addition, decoding raw array outputs via `inverse_transform` makes prediction cells instantly interpretable rather than presenting cryptic index integers.
**Action:** Always replace deprecated `predict_classes` logic with argmax prediction decoded via a trained label encoder, clear cell execution counts/outputs before saving changed notebooks, and ensure matplotlib charts use both distinct marker styles and line styles alongside standardized legends.
